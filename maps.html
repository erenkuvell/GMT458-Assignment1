Web GIS Applications

This page demonstrates interactive web mapping applications developed using OpenLayers and Leaflet.

OpenLayers Map

An interactive map created using the OpenLayers JavaScript library.

Issue 1: Marker Overlap

To prevent marker overlap at small scales, the marker layer is only visible when the map is zoomed in beyond a defined threshold. In this project, markers become visible from zoom level 11.

Issue 2: Repeating World

Horizontal world repetition is disabled by setting the OpenLayers source property wrapX: false.

Leaflet Map

An interactive map created using the Leaflet JavaScript library.

Leaflet Implementation

Marker visibility is controlled according to the current zoom level using the zoomend event.

Horizontal repetition of map tiles is prevented using the noWrap: true option.

Web GIS Features

  • OpenLayers interactive map
  • Leaflet interactive map
  • Zoom-dependent marker visibility
  • Prevention of horizontal world repetition
